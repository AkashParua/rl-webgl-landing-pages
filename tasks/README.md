# Generated Harbor bundles

Each accepted task is a directory with the Harbor layout:

```
<task-name>/
  task.toml        schema 2.0
  instruction.md   generated, leak-checked
  environment/     agent image (brief, scaffold, no verifier)
  tests/           verifier image (Dockerfile, test.sh, gates, CTRF)
  solution/        reference scene for the oracle run
```

Generated by `make pipeline`.
